# **Purpose/Why**:
---
Asciinema solves the problem of <mark style="background: #BBFABBA6;">easily recording and sharing terminal sessions</mark>. <mark style="background: #BBFABBA6;">Unlike traditional screen recorders that capture pixel data, asciinema records text output and timings, resulting in lightweight, searchable, and copy-pasteable "asciicasts."</mark> This is incredibly important for creating tutorials, documenting command-line workflows, sharing reproducible bug reports, and showcasing command-line tools without relying on heavy video files or screenshots. It's particularly useful in the Linux ecosystem where command-line interactions are prevalent.

# **Core Explanation:**
---
Asciinema is a free and open-source terminal session recorder. It records your terminal interactions (commands typed, output received) and saves them as a JSON-based `.cast` file. This format preserves the original text, allowing for features like pausing, searching, and copying text directly from the playback. It's designed to be lightweight and efficient, providing a superior experience for sharing command-line work compared to video recordings.

**Key Characteristics:**
* **Lightweight:** Records text, not pixels, resulting in small file sizes.
* **Searchable/Copyable:** Text from the recording can be selected and copied.
* **Reproducible:** Captures the exact sequence of commands and outputs.
* **Shareable:** `.cast` files can be easily uploaded to asciinema.org or shared locally.
* **Playback Control:** Allows pausing, seeking, and adjusting playback speed.

**How it Works:**
When you start a recording, asciinema captures the standard input and output streams of your terminal session. It logs every character typed and displayed, along with the precise timestamps. This data is then stored in a `.cast` file. When playing back, asciinema essentially "replays" these events in your terminal, mimicking the original session.

# **Related Concepts:**
---
* **Terminal Emulators:** Asciinema records sessions *within* a terminal emulator (e.g., GNOME Terminal, Konsole, Alacritty). It's a tool *for* the terminal, not a replacement for it.
* **Shell (Bash, Zsh, etc.):** The commands you type and execute are processed by your shell. Asciinema captures the interaction between you and the shell.
* **Screen Recording Software (e.g., OBS Studio, SimpleScreenRecorder):** These tools capture entire graphical desktop screens as video. While they can record a terminal, the output is pixel-based, resulting in larger files and non-copyable text. Asciinema is specialized for terminal text, offering unique advantages.
* **GIF Converters:** Tools like `agg` (Asciinema Gif Generator) or `asciicast2gif` are often used in conjunction with asciinema to convert `.cast` files into animated GIFs for broader compatibility, especially on platforms that don't support native asciicast embedding.
* **Markdown:** Asciicasts can be easily embedded into Markdown files using specific syntax (e.g., for GitHub, or with custom renderers), making documentation richer.

# **Examples:**
---
```bash
# Start a new recording session. 
# This will save to a temporary file, which you'll be prompted to upload or save locally when you exit.
asciinema rec

# To save the recording directly to a specific file (e.g., my_session.cast)
# This is generally preferred for local storage and later playback/conversion.
asciinema rec my_session.cast

# Example commands you might type during a recording session:
# ls -l
# pwd
# echo "Hello from asciinema!"
# cd /tmp
# mkdir test_dir
# rm -rf test_dir

# To stop the recording session:
# Simply type 'exit' into the terminal where asciinema is recording.
# The recording will stop and you'll be prompted about saving/uploading.
exit

# Play back an existing asciicast file.
# Replace 'my_session.cast' with the path to your recording file.
asciinema play my_session.cast

# During playback, you can control it:
# Spacebar: Pause/Resume playback
# Ctrl+C: Stop playback

# Convert an asciicast file into an animated GIF.
# 'agg' is a separate tool, often installed via Python's pip.
# This command converts 'my_session.cast' into 'my_session.gif'.
# Note: GIF conversion can sometimes be slow and result in larger files than the original .cast.
agg my_session.cast my_session.gif

# To upload a recording to asciinema.org (requires an account for managing uploads):
# After 'asciinema rec' and 'exit', you'll be given an option to upload.
# You can also upload an existing file:
asciinema upload my_session.cast 
```

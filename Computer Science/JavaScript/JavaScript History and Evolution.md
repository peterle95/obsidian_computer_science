    const line = lines[i];
    
    // Track code blocks
    if (line.trim().startsWith('```')) {
        inCodeBlock = !inCodeBlock;
        continue;
    }
    
    // Skip everything inside code blocks
    if (inCodeBlock) continue;
    
    // Check if line contains flashcard separator
    if (line.includes(';;')) {
        flashcardLines.push(line);
    }
}

const filteredLines = flashcardLines.filter(line => {
    // Only filter out lines that are clearly part of the JavaScript code
    // Be more specific with patterns to avoid false positives
    return !(
        line.trim().startsWith('const ') ||
        line.trim().startsWith('let ') ||
        line.trim().startsWith('function ') ||
        line.trim().startsWith('return ') ||
        line.trim().startsWith('if (') ||

# **Core Explanation:**

JavaScript's journey is a fascinating story of rapid development, standardization battles, and eventual ubiquity in web and software development.

* **Conception (1995):**
    * Created by **Brendan Eich** at **Netscape Communications**.
    * Initially named **Mocha**, then **LiveScript**, and finally **JavaScript**. The "Java" in JavaScript was a marketing decision to capitalize on Java's popularity at the time, though the languages are very different.
    * The primary goal was to provide a scripting language for the Netscape Navigator browser, enabling dynamic interactivity on web pages, something HTML alone couldn't do. It was designed to be simple enough for web designers and part-time programmers.

* **Early Browser Wars and Standardization (1996-1999):**
    * Microsoft responded with **JScript** for Internet Explorer, which was largely compatible but had its own quirks, leading to cross-browser compatibility issues.
    * To promote standardization, Netscape submitted JavaScript to **ECMA International**.
    * In **1997**, **ECMAScript** was established as the official standard for the language (ECMA-262). JavaScript is the most well-known implementation of the ECMAScript standard.
    * **ECMAScript 3 (ES3)**, released in December 1999, became the baseline for modern JavaScript for many years, introducing features like regular expressions, try/catch error handling, and more robust string/array methods.

* **The "Dark Ages" and Resurgence (Early 2000s - 2008):**
    * After ES3, ECMAScript 4 was planned with ambitious features but ultimately abandoned due to disagreements among stakeholders.
    * For several years, JavaScript development saw less dramatic innovation, though its use in creating DHTML (Dynamic HTML) effects grew.
    * The rise of **AJAX (Asynchronous JavaScript and XML)** in the mid-2000s (popularized by applications like Google Maps and Gmail) revolutionized web development, allowing pages to fetch data and update content without full reloads. This reignited interest and development in JavaScript.

* **The Modern Era - ES5 and Beyond (2009 - Present):**
    * **ECMAScript 5 (ES5)** was released in **2009**. It introduced significant enhancements like strict mode (`'use strict'`), JSON support, new Array methods (e.g., `forEach`, `map`, `filter`), and Object methods (e.g., `Object.create`, `Object.defineProperty`). ES5 became widely adopted and formed the basis of JavaScript development for years.
    * **Node.js** emerged in **2009**, created by Ryan Dahl, allowing JavaScript to run on the server-side. This dramatically expanded JavaScript's ecosystem and use cases.
    * **ECMAScript 2015 (ES6)** was a landmark release and the most significant update to the language. It introduced major new syntax and features like `let` and `const` declarations, arrow functions, classes, template literals, destructuring assignments, modules, promises, and more.
    * **Annual Releases (ES2016+):** Since ES2015, ECMA International has adopted an annual release cycle for new ECMAScript versions (ES2016, ES2017, etc.). This allows for smaller, more frequent updates, making it easier for browser vendors and developers to adopt new features incrementally. Notable additions include `async/await` (ES2017), rest/spread properties for objects (ES2018), `Promise.allSettled` (ES2020), and private class methods (ES2022).
    * **Dominance and Ecosystem:** JavaScript, with its vast ecosystem of libraries (e.g., [[React]], Angular, Vue.js) and tools (npm, Webpack, Babel), is now a dominant language for front-end web development, back-end development (Node.js), mobile apps (React Native, NativeScript), desktop apps (Electron), and even IoT.

* **Future:** The language continues to evolve with ongoing proposals and refinements driven by the TC39 committee (the technical committee responsible for ECMAScript). The focus remains on improving developer ergonomics, performance, and adding features to meet the demands of modern application development.

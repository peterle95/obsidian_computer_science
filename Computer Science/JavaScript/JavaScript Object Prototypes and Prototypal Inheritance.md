# **Core Explanation:**

JavaScript uses **prototypal inheritance** where objects can inherit properties and methods from other objects through the **prototype chain**. ==Every JavaScript object has a hidden Prototype property (accessible via `__proto__` or `Object.getPrototypeOf()`) that points to another object called its prototype.==

**Key Concepts:**
- **Prototype Chain**: When accessing a property, JavaScript first looks in the object itself, then its prototype, then the prototype's prototype, continuing until `null`
- **Constructor Functions**: Functions used with `new` keyword have a `prototype` property that becomes the `Prototype` of created instances
- **Object.create()**: Creates objects with a specified prototype directly
- **Inheritance**: Child objects inherit properties/methods from parent prototypes without copying them

**Prototype vs __proto__:**
- `Constructor.prototype`: The object that becomes the prototype for instances created by that constructor
- `instance.__proto__`: <mark style="background: #FF5582A6;">Points to the actual prototype object</mark> (same as `Object.getPrototypeOf(instance)`)

```javascript
// Constructor function approach
// Define a constructor function for the base Animal class
// This is the parent class that will be inherited by other animal types
function Animal(name) {
  this.name = name; // Initialize the name property for all animals - stores the animal's name
}

// Add a method to Animal's prototype that all animals can inherit
// Using prototype is more memory efficient than defining methods in the constructor
Animal.prototype.speak = function() {
  console.log(`${this.name} makes a sound`); // Generic sound method for all animals
  // Using template literals to include the animal's name in the output
};

// Define a constructor function for Dog, which inherits from Animal
// Dog is a subclass (child class) of Animal
function Dog(name, breed) {
  Animal.call(this, name); // Call the parent constructor to set the name property - this is how we inherit properties
  this.breed = breed; // Add a breed property specific to dogs - extends the parent class with new properties
}

// Set up inheritance chain
Dog.prototype = Object.create(Animal.prototype); // Make Dog inherit from Animal - establishes the prototype chain
Dog.prototype.constructor = Dog; // Fix the constructor property to point back to Dog - important for maintaining proper inheritance

// Add a method specific to Dog's prototype
// This method only exists on Dog instances, not on the parent Animal class
Dog.prototype.bark = function() {
  console.log(`${this.name} barks!`); // Dogs can bark (specific behavior)
  // This is an example of extending functionality in the child class
};

// Create an instance of Dog
const myDog = new Dog('Rex', 'German Shepherd'); // Instantiate a new Dog object with name and breed
myDog.speak(); // 'Rex makes a sound' (method inherited from Animal) - demonstrates inheritance working
myDog.bark();  // 'Rex barks!' (method defined on Dog's prototype) - demonstrates child-specific method

// Object.create() approach - an alternative way to implement prototypal inheritance
// Create a base animal object with a speak method
const animal = {
  speak() {
    console.log(`${this.name} makes a sound`); // Generic sound method
    // This is the prototype object that will be the base for other objects
  }
};

// Create a dog object that inherits from animal
const dog = Object.create(animal); // Sets animal as the prototype of dog - direct prototype linking without constructors
dog.name = 'Buddy'; // Set the name property on the dog object - instance property
dog.bark = function() {
  console.log(`${this.name} barks!`); // Add a bark method specific to the dog object - instance method
  // This method is only available on this specific dog object
};

dog.speak(); // 'Buddy makes a sound' (inherited) - demonstrates property lookup through prototype chain

// Checking the prototype chain - these demonstrate how JavaScript's prototype chain works
console.log(myDog.__proto__ === Dog.prototype);        // true - myDog's prototype is Dog.prototype
console.log(Dog.prototype.__proto__ === Animal.prototype); // true - Dog's prototype's prototype is Animal.prototype
console.log(Animal.prototype.__proto__ === Object.prototype); // true - Animal's prototype's prototype is Object.prototype
// These lines verify the multi-level inheritance chain: myDog → Dog → Animal → Object
```

What is the prototype chain and how does property lookup work in JavaScript?;; The prototype chain is a series of linked objects where each object has a `[[Prototype]]` reference. When accessing a property, JavaScript searches the object first, then its prototype, then the prototype's prototype, continuing up the chain until found or reaching `null`.

What's the difference between `Constructor.prototype` and `instance.__proto__`?;; `Constructor.prototype` is the object that will become the prototype for instances created by that constructor function. `instance.__proto__` points to the actual prototype object of that instance (equivalent to `Object.getPrototypeOf(instance)`).

How do you set up prototypal inheritance between two constructor functions?;; Use `Child.prototype = Object.create(Parent.prototype)` to set up the prototype chain, then `Child.prototype.constructor = Child` to fix the constructor reference. Call the parent constructor with `Parent.call(this, args)` in the child constructor.

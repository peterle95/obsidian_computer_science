## Purpose/Why:
---

JavaScript Event Listeners solve the fundamental problem of creating interactive web applications by enabling developers ==to respond to user actions== (clicks, keyboard input, mouse movements, etc.) and browser events (page load, resize, etc.). They are essential for building dynamic user interfaces because they allow JavaScript code to execute in response to specific events rather than running continuously, making applications more efficient and responsive.

## Core Explanation:
---

Event listeners are functions that wait for and <mark style="background: #BBFABBA6;">respond to specific events on DOM elements</mark>. The ==`addEventListener()` method attaches an event handler to an element without overwriting existing handlers, while `removeEventListener()` removes previously attached handlers.== This system uses an event-driven programming model where code execution is triggered by events rather than following a linear flow.

Key characteristics:
>- **Non-blocking**: Listeners wait passively until events occur
>- **Multiple handlers**: Multiple listeners can be attached to the same event
>- **Event propagation**: Events bubble up through the DOM hierarchy
>- **Event object**: Provides detailed information about the triggered event

## Related Concepts:
- **[[JavaScript What is the DOM (Document Object Model)]]**: Event listeners operate on DOM elements
- **Event Bubbling/Capturing**: How events propagate through the DOM tree
- **[[JavaScript Callback Functions]]**: Event handlers are callback functions executed when events fire
- **Event Object**: Contains event data passed to handler functions
- **Event Delegation**: Using event bubbling to handle events on parent elements
- **[[JavaScript Async⧸Await (ES8)]]**: Events are handled asynchronously in the event loop

```js
// Basic click event listener
const button = document.getElementById('myButton');

// Adding an event listener
button.addEventListener('click', function(event) {
    // This function executes when the button is clicked
    console.log('Button was clicked!');
    console.log('Event type:', event.type); // Outputs: "click"
    console.log('Target element:', event.target); // The button element
});

// Multiple event listeners on the same element
button.addEventListener('mouseenter', function() {
    // Changes button color when mouse hovers over it
    this.style.backgroundColor = 'lightblue';
});

button.addEventListener('mouseleave', function() {
    // Resets button color when mouse leaves
    this.style.backgroundColor = '';
});

// Event listener with options (once, passive, capture)
document.addEventListener('scroll', function(event) {
    // This listener will only fire once due to 'once: true'
    console.log('Page scrolled for the first time');
}, { once: true, passive: true });

// Removing an event listener (must reference the same function)
function handleClick(event) {
    console.log('Handling click event');
}

// Add the listener
button.addEventListener('click', handleClick);

// Remove the listener later
button.removeEventListener('click', handleClick);

// Event delegation example - handling events on dynamically created elements
document.getElementById('container').addEventListener('click', function(event) {
    // Check if the clicked element has a specific class
    if (event.target.classList.contains('dynamic-button')) {
        console.log('Dynamic button clicked:', event.target.textContent);
    }
});

// Keyboard event listener
document.addEventListener('keydown', function(event) {
    // Responds to keyboard input
    if (event.key === 'Enter') {
        console.log('Enter key was pressed');
    }
    // Prevent default behavior for specific keys
    if (event.key === 'F5') {
        event.preventDefault(); // Prevents page refresh
        console.log('F5 refresh prevented');
    }
});

// Form submission event
const form = document.getElementById('myForm');
form.addEventListener('submit', function(event) {
    // Validate form before submission
    const input = document.getElementById('email');
    if (!input.value.includes('@')) {
        event.preventDefault(); // Prevents form submission
        alert('Please enter a valid email address');
    }
});
```

What is the primary purpose of JavaScript Event Listeners?;; To create interactive web applications by enabling developers to respond to user actions (clicks, keyboard input, mouse movements) and browser events, making applications more efficient and responsive through event-driven programming

What is the difference between addEventListener and removeEventListener?;; addEventListener attaches an event handler to an element without overwriting existing handlers, while removeEventListener() removes previously attached handlers. Both methods allow multiple listeners on the same event.

What are the key characteristics of JavaScript Event Listeners?;; Non-blocking (wait passively until events occur), Multiple handlers (multiple listeners can be attached to the same event), Event propagation (events bubble up through DOM hierarchy), and Event object (provides detailed information about triggered events).

What concepts are closely related to Event Listeners?;; DOM (Document Object Model), Event Bubbling/Capturing, Callback Functions, Event Object, Event Delegation, and Asynchronous Programming - all work together in the event-driven programming model.

How do you properly remove an event listener in JavaScript?;; You must call removeEventListener() with the exact same function reference that was used in addEventListener(). Anonymous functions cannot be removed, so you need to store the function in a variable first.

What is event delegation and why is it useful?;; Event delegation uses event bubbling to handle events on parent elements instead of individual child elements. It's useful for handling events on dynamically created elements and improving performance by reducing the number of event listeners.

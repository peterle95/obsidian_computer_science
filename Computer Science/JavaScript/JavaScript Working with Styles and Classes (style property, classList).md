    if (line.trim().startsWith('```')) {
        inCodeBlock = !inCodeBlock;
        continue;
    }
    
    // Skip everything inside code blocks
    if (inCodeBlock) continue;
    
    // Check if line contains flashcard separator
    if (line.includes(';;')) {
        flashcardLines.push(line);

}

    // Only filter out lines that are clearly part of the JavaScript code

# **Purpose/Why**:
---

Working with styles and classes in JavaScript is essential for creating dynamic and interactive web pages. It allows developers to change the appearance of HTML elements in response to user actions, data changes, or other events. The `style` property offers direct, granular control over an element's inline styles, while the `classList` property provides a more powerful and maintainable way to apply and remove predefined styles by manipulating an element's CSS classes. Mastering these tools is crucial for building modern, responsive, and user-friendly web applications.

# **Core Explanation:**
---

There are two primary ways to manipulate the styling of HTML elements using JavaScript:

1.  **The `style` Property**: Every HTML element has a `style` property that represents its inline styles (the `style` attribute in the HTML tag). You can use this property to get and set specific CSS properties for that element. CSS properties with hyphens (e.g., `background-color`) are converted to camelCase (e.g., `backgroundColor`). While it offers direct control, it's generally best for dynamic, one-off style changes, as it can make your CSS harder to manage.

2.  **The `classList` Property**: This property provides a more structured way to manage an element's classes. It returns a `DOMTokenList`, which is a special type of collection with methods for adding, removing, toggling, and checking for the existence of classes. This is the preferred method for styling because it separates your styling logic (in CSS) from your application logic (in JavaScript), leading to cleaner and more maintainable code.

# **Related Concepts:**
---

*   **CSS (Cascading Style Sheets)**: The language used to describe the presentation of a document written in a markup language like HTML. JavaScript's style and class manipulation capabilities are used to dynamically apply and change the CSS rules that are applied to elements.
*   **DOM (Document Object Model)**: The programming interface for HTML documents. To manipulate the style or classes of an element, you first need to select that element from the DOM using methods like `getElementById()` or `querySelector()`.
*   **`className` Property**: A legacy property that gets or sets the entire `class` attribute of an element as a single string. It is less flexible than `classList` because you have to manually parse the string to add or remove individual classes.
*   **`window.getComputedStyle()`**: A method that returns an object containing the values of all CSS properties of an element, after applying all active stylesheets and resolving any basic computation those values may contain. It's a read-only way to get the actual, rendered style of an element.

# **Examples:**
---

```html
<!DOCTYPE html>
<html>
<head>
  <title>Styles and Classes</title>
  <style>
    .highlight {
      background-color: yellow;
      font-weight: bold;
    }

    .error {
      color: red;
      border: 1px solid red;
    }
  </style>
</head>
<body>

  <p id="my-paragraph">This is a paragraph.</p>

  <script>
    // Get a reference to the paragraph element
    const p = document.getElementById('my-paragraph');

    // --- Using the style property ---
    // Change the color and font size directly
    p.style.color = 'blue';
    p.style.fontSize = '20px';

    // --- Using the classList property ---
    // Add the 'highlight' class to the paragraph
    p.classList.add('highlight');

    // Add the 'error' class as well
    p.classList.add('error');

    // Remove the 'highlight' class after 2 seconds
    setTimeout(() => {
      p.classList.remove('highlight');
    }, 2000);

    // Toggle the 'error' class every second
    setInterval(() => {
      p.classList.toggle('error');
    }, 1000);

    // Check if the paragraph has the 'highlight' class
    console.log('Has highlight class:', p.classList.contains('highlight')); // true
  </script>

</body>
</html>
```

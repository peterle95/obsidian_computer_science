# **Purpose/Why**:

---

==A C++ functor, or function object, is a class or teststruct that overloads the function call operator operator. This allows an object of the class to be called as if it were a function. The primary problem functors solve is the limitation of regular functions, which cannot maintain state between calls. Functors, being objects, can have member variables to store state.==

==They are particularly important when working with the Standard Template Library (STL)==, as many algorithms like std::sort, std::transform, and std::count_if ==accept functors as arguments to customize their behavior==. This allows for ==more flexible and reusable code.== For example, instead of writing multiple functions to add different values to a collection of numbers, you can create a single functor that is initialized with the value to be added.

# **Core Explanation:**
---

<mark style="background: #FF5582A6;">A functor is an object that can be treated like a function</mark>. <mark style="background: #FF5582A6;">This is achieved by defining a class or struct and overloading the function call operator, operator.</mark> <mark style="background: #FF5582A6;">When an object of this class is created, it can be "called" using the same syntax as a function call.</mark>

**Key Characteristics:**

- **Stateful:** Unlike regular functions, <mark style="background: #BBFABBA6;">functors can maintain a state</mark>. <mark style="background: #BBFABBA6;">Because they are objects, they can have member variables to store data that persists across multiple calls.</mark>

- **Customizable:** The behavior of a <mark style="background: #BBFABBA6;">functor can be customized at runtime</mark> by passing arguments to its constructor. This allows for the creation of flexible and reusable components.

- **Overloadable:** The <mark style="background: #BBFABBA6;">operator can be overloaded to accept different numbers or types of parameters</mark>, providing more flexibility than a standard function.

- **Performance:** <mark style="background: #BBFABBA6;">In many cases, the compiler can inline the call to a functor's operator</mark>, which can <mark style="background: #BBFABBA6;">lead to better performance compared to a function pointer.</mark>

# **Related Concepts:**
---

- **Function Pointers:** These are a feature from C that allow you to pass functions as arguments. However, function pointers are stateless and less flexible than functors. Functors are often more efficient as their calls can be inlined by the compiler.

- **Lambda Expressions (C++11 and later):** Lambda expressions provide a concise syntax for creating anonymous function objects. In essence, the compiler translates a lambda expression into a functor. For simple, localized operations, lambdas are often preferred for their readability. Functors are still valuable for more complex, stateful, or reusable operations.

- **std::function (C++11 and later):** This is a general-purpose polymorphic function wrapper. It can store, copy, and invoke any callable target, including functors, function pointers, and lambda expressions. This is useful when you need to store different types of callable objects in a single container.

# **Examples:**
---

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

// A simple functor to multiply a number by a given factor.
class MultiplyBy {
private:
    // This member variable holds the state of the functor.
    int factor;

public:
    // The constructor initializes the state of the functor.
    MultiplyBy(int x) : factor(x) {}

    // Overloading the function call operator '()'.
    // This is what makes the object callable like a function.
    int operator()(int other) const {
        return factor * other;
    }
};

int main() {
    // Create an instance of the MultiplyBy functor.
    // This functor will multiply any number by 10.
    MultiplyBy multiplyByTen(10);

    // "Call" the functor object as if it were a function.
    int result = multiplyByTen(5); // result will be 50

    std::cout << "Result: " << result << std::endl;

    // Functors are commonly used with STL algorithms like std::transform.
    std::vector<int> in = {1, 2, 3, 4, 5};
    std::vector<int> out(in.size());

    // Use a temporary functor object to multiply each element in the 'in' vector by 2
    // and store the result in the 'out' vector.
    std::transform(in.begin(), in.end(), out.begin(), MultiplyBy(2));

    // Print the contents of the 'out' vector.
    for (int i : out) {
        std::cout << i << " "; // Output: 2 4 6 8 10
    }
    std::cout << std::endl;

    return 0;
}
```

    if (line.trim().startsWith('```')) {
        inCodeBlock = !inCodeBlock;
        continue;
    }
    
    // Skip everything inside code blocks
    if (inCodeBlock) continue;
    
    // Check if line contains flashcard separator
    if (line.includes(';;')) {
        flashcardLines.push(line);

# **Core Explanation:**

Forward declaration is a programming technique where you declare an identifier (such as a class, function, or variable) before its complete definition. This tells the compiler that the identifier exists without providing its full implementation details. Forward declarations are particularly useful for reducing compilation dependencies, improving compilation time, and resolving certain circular reference issues.

# **Examples:**

```cpp
// Forward declaration of class Person
class Person;

// Class that uses Person without needing its complete definition
class Company 
{
    Person* CEO;  // Pointer to Person (only needs forward declaration)
public:
    void hireCEO(Person* newCEO);
};

// Later in the code or another file, the full definition
class Person 
{
    std::string name;
    int age;
public:
    void work();
};
```

In this example, we forward declare the `Person` class before defining the `Company` class. This allows `Company` to use `Person` as a pointer type without knowing its full implementation details. This technique reduces compilation dependencies - if `Person` changes internally, `Company` doesn't need to be recompiled. Only when we need to access `Person`'s members do we need its complete definition.

```cpp
// Forward declaration of function
void processData(int value);

// Function that uses the forward-declared function
void prepareData() 
{
    int data = 42;
    processData(data);
}

// Actual definition of the function
void processData(int value) 
{
    // Implementation here
}
```

This example shows function forward declaration. By declaring `processData()` before using it in `prepareData()`, we tell the compiler the function exists and what its signature is. This allows the code to compile even though the actual implementation of `processData()` comes later in the source file.

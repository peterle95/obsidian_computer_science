# **Core Explanation:**

Access Control in C++ dictates which parts of your code can access the members (attributes and methods) of a class. This is primarily achieved using [[Access Specifiers]]:

- 🔑 public: Members declared as public are accessible from anywhere in the program – both from within the class and from outside code that uses objects of the class.
- 🔒 private: Members declared as private are accessible only from within the class itself (i.e., by its own member functions or friend functions/classes). This is the default access level if no specifier is provided. It's key for data hiding and encapsulation.
- 🛡️ protected: Members declared as protected are accessible from within the class itself and by derived classes (subclasses) that inherit from this class. They are not accessible from unrelated outside code.

In C++, "access specifiers" and "access controls" are related concepts but not exact synonyms.
## Access Specifiers
Access specifiers are the keywords used in C++ to define the visibility and accessibility of class members:

- **public**: Members can be accessed from anywhere
- **private**: Members can only be accessed from within the same class
- **protected**: Members can be accessed within the same class and by derived classes

## Access Controls
Access controls refer to the broader concept of controlling access to class members, which includes:
- Access specifiers (public, private, protected)
- Friend declarations
- The "using" declaration (to change access in derived classes)
- Other mechanisms that control member accessibility

Access specifiers are therefore a specific implementation of access controls in C++. The term "access controls" encompasses all mechanisms used to manage access to class members, while "access specifiers" specifically refers to the three keywords that define basic visibility.

# **Related Concepts:**

- 🤝 [[C++ Friendship (friend keyword)]]: A friend class or friend function can access the private and protected members of another class, even though it's not a member of that class. This provides a controlled way to bypass standard access restrictions when necessary, but should be used sparingly.

# **Examples:**

Here's a simple C++ example demonstrating access control:

```C++
#include <iostream>
#include <string>

class MyClass {
public: // Accessible from anywhere
    std::string publicVar;

    MyClass(std::string pub, std::string prot, std::string priv)
        : publicVar(pub), protectedVar(prot), privateVar(priv) {}

    void printPrivateVar() {
        // Accessible because this is a member function
        std::cout << "PrivateVar from inside MyClass: " << privateVar << std::endl;
    }

protected: // Accessible from this class and derived classes
    std::string protectedVar;

private: // Accessible only from this class (and friend functions/classes)
    std::string privateVar;
};

class DerivedClass : public MyClass {
public:
    DerivedClass(std::string pub, std::string prot, std::string priv)
        : MyClass(pub, prot, priv) {}

    void printProtectedVarFromDerived() {
        // protectedVar is accessible here because DerivedClass inherits from MyClass
        std::cout << "ProtectedVar from DerivedClass: " << protectedVar << std::endl;
        // std::cout << privateVar; // Error: privateVar is not accessible here
    }
};

int main() {
    MyClass obj1("Public Data", "Protected Data", "Private Data");
    std::cout << "Accessing publicVar from main: " << obj1.publicVar << std::endl;
    // std::cout << obj1.protectedVar; // Error: protectedVar is not accessible from outside
    // std::cout << obj1.privateVar;   // Error: privateVar is not accessible from outside

    obj1.printPrivateVar(); // OK: public method accessing private member

    DerivedClass obj2("Pub Derived", "Prot Derived", "Priv Derived");
    std::cout << "Accessing publicVar from DerivedClass object: " << obj2.publicVar << std::endl;
    obj2.printProtectedVarFromDerived(); // OK
    obj2.printPrivateVar(); // OK: calls base class public method

    return 0;
}
```

### Explanation of Example:

- `publicVar` can be accessed directly from `main()` using `obj1.publicVar`.
- `protectedVar` cannot be accessed directly from `main()` but can be accessed by `DerivedClass`'s member function `printProtectedVarFromDerived()`.
- `privateVar` can only be accessed by `MyClass`'s own member functions, like `printPrivateVar()`. It cannot be accessed directly from `main()` or from `DerivedClass` (though `DerivedClass` can call `MyClass`'s public method `printPrivateVar()` which then accesses it).

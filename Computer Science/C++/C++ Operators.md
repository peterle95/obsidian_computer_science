    if (line.trim().startsWith('```')) {
        inCodeBlock = !inCodeBlock;
        continue;
    }
    
    // Skip everything inside code blocks
    if (inCodeBlock) continue;
    
    // Check if line contains flashcard separator
    if (line.includes(';;')) {
        flashcardLines.push(line);
    }
}

const filteredLines = flashcardLines.filter(line => {
    // Only filter out lines that are clearly part of the JavaScript code
    // Be more specific with patterns to avoid false positives
    return !(
        line.trim().startsWith('const ') ||

        line.trim().startsWith('function ') ||

# **Core Explanation:**

### What are Operators?

Operators are special symbols that perform specific operations on values, known as **operands**. They provide a concise way to express computations and manipulations within your code.

**Types of Operators**

C++ offers a rich set of built-in operators, categorized by their functionality:

### Arithmetic Operators

These perform basic mathematical calculations:

- **+** (Addition): Adds two operands.
- **-** (Subtraction): Subtracts the second operand from the first.
- ***** (Multiplication): Multiplies two operands.
- **/** (Division): Divides the first operand by the second.
- **%** (Modulo): Gives the remainder of a division operation.

### Relational Operators

Used for comparing values, producing a Boolean result (true or false):

- **(double equal sign)** (Equal to): Checks if two operands are equal.
- **!=** (Not equal to): Checks if two operands are not equal.
- **<** (Less than): Checks if the first operand is less than the second.
- **>** (Greater than): Checks if the first operand is greater than the second.
- **<=** (Less than or equal to): Checks if the first operand is less than or equal to the second.
- **>=** (Greater than or equal to): Checks if the first operand is greater than or equal to the second.

### Logical Operators

Combine Boolean expressions:

- **&&** (Logical AND): Returns true if both operands are true.
- **||** (Logical OR): Returns true if at least one operand is true.
- **!** (Logical NOT): Inverts the logical state of its operand.

### Assignment Operators

Used to assign values to variables:

- **=** (Simple assignment): Assigns the value of the right operand to the left operand.
- **+=**, **-=**, ***=**, **/=**, **%=** (Compound assignment operators): Combine an arithmetic operation with assignment.

### Bitwise Operators

Operate on individual bits of integer values:

- **&** (Bitwise AND): Performs a bitwise AND operation on each bit of the operands.
- **|** (Bitwise OR): Performs a bitwise OR operation on each bit of the operands.
- **^** (Bitwise XOR): Performs a bitwise XOR operation on each bit of the operands.
- **~** (Bitwise NOT): Inverts each bit of its operand.
- **<<** (Left shift): Shifts the bits of the first operand to the left by the number of positions specified by the second operand.
- **>>** (Right shift): Shifts the bits of the first operand to the right by the number of positions specified by the second operand.

### Other Operators

C++ includes several other important operators:

- **?:** (Conditional/ternary operator): A concise way to express if-else-like conditions.
- **::** (Scope resolution operator): Used to access members within a namespace or class.
- **.** (Member access operator): Used to access members of an object.
- **->** (Member access operator): Used to access members through a pointer.
- **[]** (Subscript operator): Used to access array elements.
- **()** (Function call operator): Used to invoke functions.
- **new** and **delete** (Dynamic memory allocation and deallocation): Used to allocate and deallocate memory at runtime.

**Operator Precedence and Associativity**

C++ has well-defined rules for how operators are grouped and evaluated in expressions:

- **Precedence:** Determines the order in which operators are applied. Operators with higher precedence are evaluated first.
- **Associativity:** Determines how operators of the same precedence are grouped. Most operators associate from left to right.

You can use parentheses to override the default precedence and associativity rules to ensure that expressions are evaluated in the desired order.

**Overloading Operators**

A powerful feature in C++ is the ability to define how standard operators behave when applied to custom data types. This is known as operator overloading. By overloading operators, you can make your code more intuitive and readable.

**Key Takeaways**

- Operators are fundamental building blocks of C++ expressions.
- Understanding operator precedence and associativity is crucial for writing correct code.
- Operator overloading allows you to extend the use of standard operators to custom data types.
